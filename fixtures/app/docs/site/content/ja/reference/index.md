リファレンスのページは、絞られた質問に手早く答
えます。作業の手順を追って説明することはしませ
ん。それは[ガイド](../guide/index.md)の役割です。

## ここにあるもの

[チップ対応表](chip-support.md)には、Fixture App
が認識するすべてのタグファミリーを、使用できる
メモリ、受け付ける書き込みモード、ロックビット
が一方向かどうかとともに掲載しています。タグを
まとめて購入する前に確認してください。

[タグセッション API](api.md)は、`TagSession` 型、
それが返すレコード、そして送出しうるすべてのエ
ラーを説明します。Fixture App のリーダーを別のア
プリに組み込む開発者向けの内容です。

## 表記

どちらのページも同じ表記を使います。サイズは、
パッケージに印字された数値ではなく、タグ自身の
ヘッダーを除いて使用できるバイト数です。

| 表記 | 意味 |
| -------- | ------- |
| `0x04` | アプリが表示する形式での 16 進数 1 バイト |
| `216 B` | ヘッダーを除いた使用可能なユーザーメモリ |
| `n/a` | そのタグファミリーには当てはまらない項目 |
| `RO` | ロックビットが設定済みのため読み取り専用 |

`n/a` と記された項目は、ゼロではなく存在しないと
いう意味です。`0 B` と報告するタグは空のペイロー
ドでロックされており、それは別の問題です。
