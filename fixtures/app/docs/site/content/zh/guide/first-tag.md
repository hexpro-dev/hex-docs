标签拿到手之后，第一次读取大约需要十秒。其中大部分时
间花在找手机上天线所在的位置，它在机身背面比多数人以
为的要靠上。

## 开始之前

Fixture App用的是手机内置的NFC读取器，所以不用配对，也
不用充电。iPhone 7以后的任何机型，只要运行iOS 16或更高
版本，都可以读取标签。

你需要一枚读取器能够对话的标签，以及一条通向它的无阻
挡路径：

- [x] 一部运行iOS 16或更高版本的iPhone 7或更新机型
- [x] 从App Store安装的Fixture App 1.0或更高版本
- [ ] 一枚NTAG 213、NTAG 215或MIFARE Ultralight标签
- [ ] 厚度小于3 mm的手机壳，或者不戴手机壳

::include[safety-note]

不是每一枚标签都会应答。MIFARE Classic标签在iPhone上
毫无反应，因为读取器不会说它们的协议；有些门禁标签则
要先完成一次密码交换才应答。[芯片支持矩阵](../reference/chip-support.md)
列出了针对1.0版本测试过的芯片。

## 读取标签

::::steps
:::step[打开扫描面板]
点按标签库屏幕中间的大圆圈，或者长按主屏幕上的应用图
标并选择“扫描”。面板会向上滑出，状态栏显示“等待标签”。

读取器会保持唤醒60秒。如果范围内一直没有标签，面板会
自己关闭，标签库里也不会新增任何内容。
:::

:::step[把标签贴在手机顶部]
把手机顶边平贴在标签上，两者都保持不动。状态栏会变成
“已检测到标签”，手机会发出一声短促的提示音。

位置比压力更要紧：

- 天线横贯顶边，大约在摄像头模组下方一厘米处。
- 让标签与手机保持平行，不要斜着放。
- 先把MagSafe卡包或金属卡片挪开。
:::

:::step[检查记录并保存]
读取结束后，面板会按存储顺序列出标签上的每一条NDEF记
录。Fixture App能识别URL、文本和Wi-Fi记录，并为每一条
显示预览。其余内容一律以原始字节列出。

点按“保存”留下这枚标签，或者点按“丢弃”关闭面板，不向
标签库写入任何内容。
:::
::::

:::figure[扫描面板，正在等待标签进入范围]
![等待标签的扫描面板](../../../assets/scan-screen.png)
:::

:::warning[部分读取看起来像是成功]
带有密码保护区域的标签只应答读取的前一部分，其余部分
一律拒绝。Fixture App会显示它拿到的内容，并在标签名称
下面写上“记录不完整”。相信一次门禁标签的读取结果之前，
先找一找这行字。
:::

:::tip
打开“设置 > 扫描 > 保持面板打开”，就可以一口气读取多枚
标签。标签库会把这次会话里的所有内容归到同一个标题下。
:::

## 读取之后

保存下来的标签会进入标签库，最新的排在最前面，名称下
方是芯片类型和读取时间。点按其中一条会打开标签详情，
那里把原始字节和解码后的记录并排显示。

![列出三条NDEF记录的一次完整读取](../../../assets/scan-screen.png)

重命名标签只会改变你在标签库里看到的名字。除非使用写
入面板，否则不会有任何内容写回标签本身，那是另一套单
独的操作。

## 如果读取没有完成

读取器会自行重试。前两次尝试是悄悄进行的，彼此相隔大
约一秒。从第三次尝试起，面板会开始报告它正在做什么：

3. 状态栏出现“仍在查找”，提示音停止。
4. 读取器退回到较慢的轮询速率。
5. 会话以“读取完成前标签已丢失”结束。

连续两次都走到第五次尝试的读取，问题通常出在标签而不
是手机上。[扫描不成功时](troubleshooting.md)按值得排查
的先后顺序讲清了各种原因。
