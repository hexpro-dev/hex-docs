参考页面用来快速回答一个具体的问题。它们不会带你走完
一项任务，那是[指南](../guide/index.md)的事。

## 这里有什么

[芯片支持矩阵](chip-support.md)列出了Fixture App能识别
的每一个标签系列，包括可用存储空间、各自接受的写入方
式，以及它的锁定位是否不可逆。批量买标签之前先查一查。

[标签会话API](api.md)说明了`TagSession`类型、它返回的记
录，以及它可能抛出的每一种错误。这一页是写给要在别的
应用里嵌入Fixture App读取器的开发者的。

## 约定

两个页面用同一套记法。尺寸指的是扣掉标签自身头部之后
你可以用的字节数，不是包装上印的那个数字。

| 记法 | 含义 |
| -------- | ------- |
| `0x04` | 十六进制的单个字节，按应用打印的样子 |
| `216 B` | 可用的用户存储空间，不含头部 |
| `n/a` | 该字段不适用于这一标签系列 |
| `RO` | 只读，因为锁定位已经置位 |

标记为`n/a`的字段是不存在，而不是零。报告`0 B`的标签是
带着空负载被锁定了，那是另一回事。
